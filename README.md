# Tour Management System
## About
TourBD aims to digitize the core workflow of a tour management agency, from user registration and package browsing to tour booking, payments, guide and vehicle assignment, route updates, and administrative reporting.

## How to Run
Open `index.html` in a browser (or use Live Server in VS Code).

## Demo Login Accounts
- **Admin:** `admin` / `admin1234`
- **Agency Manager:** `manager` / `manager1234`
- **Tour Guide:** `guide` / `guide1234`
- **Tourist:** `tourist` / `tourist1234`

## Folder Structure
- `index.html`, `login.html`, `register.html`, `tourist.html`, `guide.html`, `manager.html`, `admin.html`
- `css/style.css` - External stylesheet
- `js/` - JavaScript files (`data.js`, `common.js`, and page scripts)
- `images/` - Tour destination images
